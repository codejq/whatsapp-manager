WhatsApp Manager تطبيق مجاني ومفتوح المصدر لنظام ويندوز، مصمم لغير المختصين. اربط واتساب بمسح رمز QR،
وأنشئ قواعد بسيطة، ويعمل التطبيق بهدوء في شريط المهام:

- **عندما** تصل رسالة في *مجموعة «عملاء المبيعات»* **و**فيها *رابط* ← **أرسلها بالبريد** إلى `leads@company.com`
- **عندما** يكتب *أحمد* ← **حوّلها عبر واتساب** إلى `+966 5x xxx xxxx`
- **عندما** تحتوي أي رسالة على «عاجل» ← **أرسلها إلى مجموعة «المدراء»**

## المزايا

- تثبيت بنقرة واحدة، بدون صلاحيات مدير، وبدون أي إعدادات — الاتصال بواتساب مدمج.
- واجهة عربية افتراضياً، والإنجليزية متاحة.
- معالج قواعد سهل: راقب أي محادثة أو كل المجموعات أو المحادثات الخاصة أو محادثات وأشخاصاً محددين؛ شروط
  للروابط والكلمات (تتم مطابقة الهمزات والتشكيل تلقائياً) والكلمات المستبعدة وأنواع الرسائل؛ وأرسل إلى جهات
  اتصال أو أرقام أو مجموعات أو عناوين بريد.
- البريد عبر **حساب SMTP الخاص بك** (Gmail وOutlook وMicrosoft 365 وYahoo وZoho وiCloud أو أي خادم) مع
  اكتشاف تلقائي وزر تجربة.
- لا يرسل الرسالة نفسها مرتين لنفس الوجهة، ولا يدخل في حلقات تكرار، ولا يغرقك برسائل قديمة بعد إطفاء الجهاز.
- يعمل مع بدء ويندوز، ويعيد الاتصال تلقائياً، ويتعافى من الأعطال.
- سجل يعرض كل رسالة والقاعدة التي طابقتها وإلى أين أُرسلت — مع زر «إرسال مرة أخرى».
- كل شيء يبقى على جهازك. بدون حسابات أو سحابة أو تتبع.

## التثبيت

نزّل `WhatsAppManager-Setup-x.y.z.exe` من [آخر إصدار](../../releases/latest) وشغّله. تتوفر أيضاً نسخة محمولة `.zip`.

> قبل توقيع التطبيق رقمياً قد يظهر تحذير SmartScreen «حمى Windows جهازك». اضغط **مزيد من المعلومات ← تشغيل على أي حال**.

المتطلبات: ويندوز 10 (1809 أو أحدث) أو 11، 64-بت.

> **نصيحة:** استخدم رقم واتساب مخصصاً. قد يقيّد واتساب الأرقام التي ترسل رسائل آلية كثيرة.
